Discord staff management, moderation, tickets, and partnerships — all in one bot.

Get Started View on GitHub

Features

Staff Promotions

Configurable promotion ladder with role progression and case logging.

Infractions

Issue strikes, suspensions, and terminations with full case history.

Moderation

Mute, kick, ban, and unban with security logging.

Tickets

Private support tickets with close controls.

Partnerships

Application review and announcement workflow.

Appeals

Staff case appeals with accept/deny review.

Commands

  • /promo - Promote a staff member
  • /infraction - Issue a staff infraction
  • /history - View a member's case history
  • /void - Void a staff case
  • /mute, /ban, /kick, /unban - Moderation
  • /ticket-panel - Post a ticket panel
  • /partnership - Submit a partnership application
  • /appeal - Submit an appeal
  • /embed - Create a custom embed
  • /config - Configure the bot

Setup

  1. Clone the repository and open the Bot folder.
  2. Run npm install.
  3. Copy .env.example to .env and fill in DISCORD_TOKEN and CLIENT_ID.
  4. Run npm run deploy to register slash commands.
  5. Run npm start to launch the bot.
